Nintendo EAD/SRD Super Mario Advance engine revision detection.

A full-corpus audit of all 3,377 GBA ROMs identifies 35 ROM images powered by the EAD/SRD custom DirectSound mixer across 2 distinct ARM7TDMI IWRAM kernel revisions:

  1. EadSmaVersion::Sma23Shift8 (12 ROMs — Super Mario Advance 2 USA/Europe/Japan/China, Super Mario Advance 3 USA/Europe/Japan in retail and Virtual Console forms, the China-market Yoshi’s Island release, and a China-market Mario & Luigi prototype whose embedded Mario Bros. classic mode uses this driver):
    • Voice mixer accumulates (sample * volume) >> 8 per output frame (ARM mul + add ..., asr #8, truncated to i16 on store).
    • DMA converter stores the low byte of each i16 accumulator, saturating to [-128, 127] only when the value lies outside that range ((v & 0xFF80) != 0 && != 0xFF80).
    • Buffer combine attenuates with round-half bias 1 << (shift - 1) for all source values, negative or not.
  2. EadSmaVersion::Sma4Mla (23 ROMs — all Super Mario Advance 4 regional/revision/Virtual Console/Switch Online images, the Mario Bros. classic mode inside Super Mario Advance 3, and The Legend of Zelda: A Link to the Past & Four Swords USA/Europe/Japan):
    • Voice mixer accumulates sample * volume with no shift (ARM mla), so its voice volumes are pre-scaled by 1/256 relative to the older revision.
    • DMA converter first computes (v + (v < 0 ? 127 : 0)) >> 7 (round-toward-zero division by 128), then applies the same [-128, 127] saturation test to the shifted value.
    • Buffer combine attenuates with bias (1 << shift) - 1 applied only to negative source values (ceil-style rounding).

Both revisions share the same voice-render wrapper semantics (Q8 phase, 176-sample DMA frames, planar left/right i16 mix buffers), the same 16-byte sample descriptor layout, and identical ARM unsigned/signed division helpers. Super Mario Advance 3 cartridges contain both revisions (the main game uses Sma23Shift8; the Mario Bros. classic mode uses Sma4Mla); EadSmaVersion::detect_from_bytes reports the main-game revision in that case.
