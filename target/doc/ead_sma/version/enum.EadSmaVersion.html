Expand description

Distinct Nintendo EAD/SRD ARM7TDMI mixer revisions discovered across the GBA corpus.

Variants§

§

Sma23Shift8

SMA2/SMA3 revision (12 ROMs): mixer accumulates (sample * volume) >> 8; DMA converter saturates the raw i16 accumulator; combine uses the unconditional round-half bias 1 << (shift - 1).

§

Sma4Mla

SMA4 revision (23 ROMs): mixer accumulates sample * volume via mla with no shift; DMA converter pre-scales by >> 7 with negative bias +127 before saturating; combine biases only negative values by (1 << shift) - 1.

pub const fn mixer_shifts_product(self) -> bool

Returns true when the voice mixer shifts each product right by 8 before accumulating (Sma23Shift8), or false when it accumulates the full product (Sma4Mla).

Source

pub fn detect_from_bytes(rom: &[u8]) -> Option<Self>

Detect the exact Nintendo EAD/SRD mixer revision from a GBA ROM image.

Matches the three ARM7TDMI IWRAM kernel signatures (DMA converter, voice mixer, buffer combine) at their revision-specific relative offsets. The kernels are copied verbatim from ROM into IWRAM by the retail driver, so the ROM signatures are byte-identical to the executing code. Returns None for ROMs that do not contain this engine (including all M4A titles such as the first Super Mario Advance, Mario Kart: Super Circuit, and F-Zero).
