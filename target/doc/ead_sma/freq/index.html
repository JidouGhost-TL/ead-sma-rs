arm_sdiv
Signed 32-bit division exactly as implemented by the driver’s ARM helper routine: returns numerator / denominator (truncating toward zero), or 0 when denominator is zero. The i32::MIN / -1 overflow case wraps to i32::MIN, matching the helper’s shift/subtract sequence.
arm_udiv
Unsigned 32-bit division exactly as implemented by the driver’s ARM helper routine: returns numerator / denominator, or 0 when denominator is zero.
freq_to_step_q8
Compute the Q8 phase increment for playing a sample recorded at sample_rate_hz through a mixer running at mix_rate_hz.
pan_gains

rate_from_timer_reload
Compute the exact DirectSound hardware sample rate in Hz for a GBA Timer0 reload value.
step_q8_to_freq
Convert a Q8 phase increment back to an effective playback rate in Hz.
